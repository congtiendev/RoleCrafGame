# Prompt Set — ROLECRAFT UI v4

Built-in image generation was used for the new raster artwork.

## Shared art direction

- Premium 2D chibi office-adventure game art.
- Restrained slight pixel edges, square highlights and crisp cel shading.
- Cobalt/deep navy, electric cyan and warm gold palette.
- Modern glass Innocom office, greenery and city skyline.
- Official Innocom logo is composited from the supplied PNG, not redrawn.
- Game backgrounds contain no dynamic copy, QR code, progress bar, participant data or controls.

## Start / Banner

- Exactly eight supplied employee characters.
- Main hero: wavy brown hair, brown rectangular glasses, light-blue rolled-sleeve shirt, orange lanyard and teal tablet.
- Main hero centered and larger; seven teammates arranged dynamically.
- ROLECRAFT logo and CTA remain separate assets.

## Loading

- No character baked into the background.
- Clear cyan route with waypoint nodes ending at a gold-blue portal.
- Runner, label and progress bar remain separate layers.

## QR Join / Participants

- Empty responsive environment with a broad calm area for JS-rendered content.
- Participants screen uses a cyan assembly ring with eight subtle docking marks.
- No baked names, avatars, QR or player count.
